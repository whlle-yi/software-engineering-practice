## 约定

**原件不复制**：课程根已有全部 6 份要求，提交目录不再复制 Word 副本，只放 `.md` 转录件。同一份文件存在两处，早晚会改错版本。

**编号与课程一致**：目录序号沿用老师资料编号（0 任务书、1 可行性、2 需求…），不另造编号体系，对照一目了然。

**到哪一步建哪一步**：不预建空目录。`第二次\`、`<项目名>\` 在真正开始对应工作时才创建。

**文档带版本**：`名称-v主.次.md`，`0.x` 内部迭代、`1.0` 起对外。同一文档只留一份，历史由 git 记录，不建"终稿-最终版"副本。

**项目本体独立成文件夹**：项目横跨需求、设计、实现三个阶段，不属于任何一次提交，因此与 `第N次\` 平级置于课程根下。选题确定后以其命名，现在不建。
