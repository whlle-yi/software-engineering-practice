## 约定

**编号与课程一致**：目录序号 = 老师资料编号（0 任务书、1 可行性报告、2 需求、3 设计）。不另造编号体系，老师对照一目了然。

**原件不动**：`0-课程要求/` 下的 Word 文件保持原名原样，只读；转录出的 Markdown 用规范化短名，便于检索与引用。

**文档带版本**：`名称-v主.次.md`，`0.x` 内部迭代、`1.0` 起对外。同一文档只留一份，旧版本由 git 记录，不建"终稿-最终版"副本。

**图文分离**：报告里插图的可编辑源文件与导出图，按需在 `1-可行性研究/图表/` 下建，不提前建。
