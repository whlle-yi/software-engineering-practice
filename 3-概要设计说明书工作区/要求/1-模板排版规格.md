## 文档结构

- 3 节：封面（段 5–20）/ 目录（段 22–52，TOC 域）/ 正文（段 53 题名「概要设计说明书」起，六章）。
- 标题样式：Heading 1（章，22pt）/ Heading 2（节，16pt，西文 Arial 是模板原样）；编号写在标题文本内（「1引言」，编号后不留空格）。模板无 Heading 3，全部两层级标题。
- 目录条目样式实测为 **目录 11 / 目录 21 / 目录 31**（带尾缀"1"，.doc 转换件特有；模板工作副本最初显示「目录 1/2」是样式名歧义，以样式表实测为准）。**WPS 重建 TOC 会把条目样式打回 Normal 或 toc N**，需按条目文本层级改回（`N.N` → 目录 21，`N标题` → 目录 11）。
- 正文段：Normal 样式 + 首行缩进 21pt（段落直接格式），**无显式行距**（模板正文为单倍行距，与 2 号模板的 1.5 倍不同，是模板原样，勿"统一"）。新段落克隆模板指导语段获得缩进。
- 页边距：上下 1 in、左右 1.25 in，版心宽 ≈14.65 cm。
- Normal 五号（10.5pt）；docDefaults = ascii/hAnsi Times New Roman + eastAsia 宋体。

## 模板坑（本次实测）

1. **TOC 域重建样式三态**：WPS 重建后条目样式可能为 Normal（首测）或 toc 1/toc 2（次测），还原目标一律是「目录 11/21」；还原逻辑按条目文本判断层级，勿按旧样式名判断。
2. **图题与图分离**：插图段高于当前页剩余空间时图整体后移，题注若在前会留在前页——**图段设 keepNext（与图题同页）、图题不设 keepNext**（表题相反：表题设 keepNext 与表同页）。
3. **三线表 tblPr 子元素必须按 OOXML schema 顺序写**（tblW→jc→tblBorders→tblLayout→tblCellMar→tblLook）；单元格左右边距缩至 57 dxa（1mm）可避免 `C,R,U,D` 类紧凑内容断行；表头行 tblHeader 跨页重复 + 表头单元格段落 keepNext 防「孤立表头」。
4. 标识符列（schedule_record / teacher_preference 等长英文）需 ≥0.24 版心宽比例，否则断行。
