## 三、技术备忘与坑

- **git 仓库在课程根**；不入库：`模板及总体要求\`（老师原件，克隆后自备）、`Mermaid 结构化分析图表练习\`（与本项目无关）、`.workbuddy\`、`.zcode\`。
- **生成 Office 文档必须用系统 python**（`C:\Users\32530\AppData\Local\Microsoft\WindowsApps\python.exe`），它才有 python-docx 和 pywin32。
- **交付件的 COM 操作（更新目录、导 PDF 等）一律用 WPS**（`KWPS.Application`，DispatchEx 独立实例 + 逐调用退避重试），**禁用 Word.Application**——本机装有真 Word，但用户工作流在 WPS，两者保存链不同；WPS 后台进程会锁文档。
- **WPS 保存链会劣化内嵌图形**（svgBlip 剥除、图片降采样）——插图一律 600dpi PNG 注入；终稿从 docx 直接导 PDF，勿以 WPS 再次保存的版本为准。
- **模板目录是真 TOC 域**，重建目录会打乱条目样式，更新后须改回模板的目录样式（各模板实测样式名见对应工作区 `要求\`）。
- **模板原样不要"统一"**：二级标题黑体、三级宋体；**指导语（"说明……"）必须删除替换**——这是最容易犯的错。
- **`git add -A` 会纳入未跟踪文件**，误加后需 `git rm --cached`。
