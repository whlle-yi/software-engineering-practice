# 《软件工程课程实践》课程大作业任务书

> **来源**：`0《软件工程课程实践》大作业任务书.docx`
> **性质**：课程总要求 —— 整个学期大作业的选题范围、目标、内容、要求、进度与评分标准
> **用途**：查阅"整门课要做什么、怎么交、怎么评分"

## 一、选题

各选课班同学可分组合作，参考历年的创新、创业学术活动的选题，结合兴趣和技术发展潮流，思考合适的软件项目的选题作为大作业的题目，展开软件的分析与设计的实践训练。也可从以下所给的参考选题中任选一题作为大作业的选题。特别鼓励同学从学习、生活实践中提出新的选题，展开软件的分析与设计。

**参考选题：**

1. 本地网络工作站流量检测系统 —— 监视本机网卡的流量、流向等数据，并能够对这些信息进行统计、检查等管理。
2. 网络工作站监视系统 —— 监视远程网络工作站的工作情况。
3. 软件工程教学演示系统 —— 课程教学、有关软件操作的多媒体演示系统。
4. 客户信息服务网络系统、网络客户服务中心系统。
5. 短信网络预定服务系统 —— 通过网页预定短信服务。
6. XX 网络娱乐软件，网络游戏软件。
7. XX 手机娱乐软件，手机游戏软件。
8. 毕业生信息服务网络系统 —— 大学毕业生咨询信息服务。
9. 手机炒股软件的设计 —— 通过移动网络实现手机炒股。
10. 微型 DBMS 系统 —— 设计一款微型数据库管理系统。

## 二、对象

选修《软件工程课程实践》课程的全体同学。

## 三、目标

通过大作业、实际动手的训练，使学生能够：

- 运用软件工程的思想，学习掌握软件系统的分析与设计；
- 掌握软件工程的方法、工具和过程；
- 掌握利用 Visio、Rational Rose、ERwin、Power Designer、Together 等常用软件工具进行软件系统分析与建模的方法；
- 掌握软件工程中标准的使用；
- 训练软件开发文档的写作，及软件原型的开发、软件核心算法的设计与实现；
- 培养软件开发团队协作精神，提高学生的专业能力和综合素质。

## 四、内容

分课内和课外完成大作业。课内的内容主要是老师布置大作业、指导选题、模拟评审、成果展示与答辩；课外以学生实际操作实践为主，内容如下：

1. **可行性分析**：根据具体的选题和软件系统的需求，进行软件项目的可行性分析，完成**可行性研究报告**。采用 Project 进行项目计划安排。对可行性研究报告进行模拟评审，各组必须认真评阅其它组的可行性研究报告，提出建议并相互评阅。
2. **需求分析**：采用结构化或者面向对象的方法，运用数据流图、数据字典、UML 等建模方法，采用 Visio、Rose、ERwin、Power Designer、Together 等工具软件，进行系统的需求调查、分析建模，完成**系统需求规格说明书**。
3. **系统设计**：进行软件系统的设计，完成**系统设计说明书**，也可以细分为概要设计、详细设计、数据库设计说明书。
4. **原型开发**：选用合适的原型开发工具或编程工具，进行系统的原型开发或核心部分的实现；有兴趣的同学可选择继续、深入完成系统的编码规范与主要子系统的编码，进行必要的测试，完成有关的**测试计划或测试报告**。

## 五、要求

1. 学生分成 **3-5 人一组**，合理分工与协作，各小组选择合适的选题，在课外完成。
2. 大作业的成果包括文档、程序或数据等，必须符合软件工程的有关**国家标准**。
3. 在课程结束前以**组为单位**提交电子稿或必要的打印稿。

## 六、实施步骤及时间表

| 周次 | 阶段任务 |
| --- | --- |
| 第 1-2 周 | 发掘与确定有意义的选题 |
| 第 3-4 周 | 搜集相关资料或进行调研，对选题进行可行性分析 |
| 第 5-6 周 | 进行立项评审 |
| 第 7-9 周 | 展开软件的深入分析，完成需求规格说明书 |
| 第 10-11 周 | 进行软件系统的设计，完成系统设计说明书（可细分为概要设计、详细设计、数据库设计说明书）等文档 |
| 第 12-13 周 | 系统原型开发或者核心功能的实现，完成编码规范、测试计划与分析等文档 |
| 第 14-15 周 | 系统演示与评审 |
| 第 16 周 | 大作业总结与完善 |

## 七、评分标准

评分依据选题的创新性、系统分析与设计的深度、软件文档的质量、实现情况、评审与答辩的情况等进行评分，**总分 80 分**。

| 评分项 | 分值 | 评价维度 |
| --- | --- | --- |
| 可行性研究 | 15 分 | 问题定义、分析的深度和宽度、文档的规范、对其它组的评阅表现 |
| 需求分析 | 15 分 | 需求分析的全面性、建模方法、工具的应用程度、文档的规范性 |
| 系统设计 | 30 分 | 包括概要设计和详细设计；系统的结构、功能划分、界面、算法的先进性、设计文档的规范性 |
| 测试计划 | 20 分 | 测试进度安排以及测试内容和目的，例如模块功能测试、接口正确性测试、数据文卷存取的测试、运行时间的测试、设计约束和极限的测试等；组织结构、内容安排、测试文档的规范性 |

评分时，同时会考虑选题的创新性、特色、总体难度，小组成员分工、协作、项目安排，演示与答辩（系统开发综述、系统运行的总体表现、回答问题）等多个方面。

## 八、格式规范

课程大作业成果包括如下文档：

1. **可行性研究报告**（参见《计算机软件产品开发文件编制指南》GB 8567-2006，GB 8567-88）
2. **需求规格说明书**（参见《计算机软件产品开发文件编制指南》GB 8567-2006，GB 8567-88）
3. **系统设计说明书**（参见《计算机软件产品开发文件编制指南》GB 8567-2006，GB 8567-88）（概要设计、详细设计）
4. **系统测试计划**（参见《计算机软件产品开发文件编制指南》GB 8567-2006，GB 8567-88）（备选）
5. **系统原型或核心功能代码**（备选）

学生提交的具体成果，由任课教师根据课程进度和学生学习的具体情况确定。
