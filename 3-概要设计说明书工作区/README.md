## 设计定稿（概要设计阶段的决定）

- 模块划分：应用服务层 M1 用户与权限管理 / M2 基础数据管理 / M3 排课约束配置 / M4 自动排课引擎（约束建模、搜索求解、冲突检测三子模块）/ M5 调课申请与审核 / M6 课表查询与通知 / M7 PiAgent 智能体（意图理解与编排、偏好提取与记忆管理两子模块）/ 公共服务层 M8 数据访问与审计（公用程序）。
- 数据结构：基础数据域（sys_user/teacher/student/class_info/course/classroom）、排课业务域（term/teaching_task/schedule_record/adjust_request）、约束与偏好域（constraint_config/teacher_preference）+ 审计日志 audit_log；MySQL 8.0（InnoDB、utf8mb4）。
- 接口：前后端 RESTful API；M4 对 M3/M5 提供求解与局部重排内部接口；M7 经 M1 鉴权白名单工具调用业务模块、HTTPS 直连外部模型 API。
- 后端实现方案（Spring Boot / Flask）保持双方案表述，列入 2.7 尚未解决的问题，详细设计阶段定。
