## 设计定稿（详细设计阶段的决定）

- 章次即模块：第 3~10 章对应 M1~M8，每章 13 小节按模板骨架；输入输出项承接 SRS 的 IPO 表，性能条目继承 SRS 3.2.2。
- M4 算法定稿：决策变量 x(t)=(星期,节次,教室)；硬约束四类（教室独占/教师不冲突/班级不冲突/容量）；适应度=硬约束罚项＋软约束加权；阶段一贪心＋回溯构造初始解，阶段二遗传（锦标赛/单点交叉/单任务重排变异/精英保留）或模拟退火（Metropolis、几何降温）二选一可配置；冲突检测全量扫描兜底，防御分支回退重试。
- M7 算法定稿：白名单工具分 read（直调 M2/M3/M4/M6）与 write（一律生成待确认项，确认后经 M3/M8 落库）；结构化校验=工具名清单比对＋字段校验；单会话上下文不长期保存。
- M5 状态机定稿：{待审核，通过，退回}；审核通过与局部重排同事务，重排不可行整体回滚保持待审核。
- 各模块单体测试计划（用例/桩/预期/进度）写入 N.12 小节，与《测试计划》衔接。
