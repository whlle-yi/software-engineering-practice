# 数据流程图（DFD）制作方法

> **用途**：描述数据**从哪里来、经过哪些加工、存放在哪里、流到哪里去**。
> **风格基准**：老师课件三页（四要素 / 分层 / 0 层图检查，2026-11-07 取色入库，色值见第四节）。
> **实现工具**：pretty-charts（matplotlib）之上的既定扩展——图元、坐标系、输出规范沿用 skill，样式按本文档覆盖。
> **本仓库状态**：需求说明书已有顶层图/0 层图（旧样式）；按本规范重绘与否由用户决定（见第九节）。

## 一、DFD 与其他图的区别（画前必读）

- **只画数据的流动**：不画判断、不画先后顺序（不同于程序流程图）；
- **不管用什么设备实现**（不同于系统流程图）；
- 与同目录《处理流程图制作方法.md》的关系：处理流程图回答"谁按什么顺序做什么"，DFD 回答"数据从哪来到哪去"——两者常配对出现（处理流程 + 数据流程）。

## 二、四要素符号规范

| 要素 | 图形 | 内容写法 | 说明 |
| --- | --- | --- | --- |
| 外部实体 | 方框 | 名称 | 系统以外的人或系统，数据的来源或去处 |
| 加工 | **圆** | **编号 + 动宾短语**（如"1 借书处理"） | 对数据进行处理 |
| 数据存储 | **双横线**（左端开口） | **编号 + 名称**（如"D1 借阅记录"） | 存放数据的地方 |
| 数据流 | 箭头线 | **线上必须写数据的名字** | 箭头方向 = 流动方向 |

## 三、分层规范

1. **顶层图**（上下文图 Context Diagram）：整个系统画成**一个加工**（只写系统名，不编号），只画外部实体和进出系统的数据流；作用 = 划出系统**边界**——哪些在系统里、哪些在系统外；
2. **0 层图**：把顶层加工分解成几个主要加工，**编号 1、2、3……**；**第一次画出系统内部的数据存储（D1、D2……）**；
3. **中间层与底层**：复杂加工继续分解，得到 1 层图、2 层图……（编号 x.y）；最下面一层叫**底层图**：里面的加工都是**基本加工**，不再分解，每个在数据字典里写一条加工条目；
4. **分层平衡**：上层图叫**父图**、下层图叫**子图**；**子图和父图进出的数据流必须对得上**（进出系统边界的数据流与顶层图一一对应）。

## 四、配色与样式（实测自课件 0 层图）

| 色值 | 元素 |
| --- | --- |
| `#FFFFFF` | 画布底（白底，学术教材风格） |
| `#1B3770` 深蓝 | 全部线条：外部实体框边、加工圆边、数据存储双横线、箭头、全部文字与数据流标签 |
| `#C00000` 红 | **仅限教学标注**（课件里的①②③④圈号），**不进正图** |

- 线宽：主体 1–1.1pt；数据存储双横线各 1pt，两线间距 ≈ 加工圆半径的 0.4 倍；
- 文字：宋体/TNR（本项目字体规范），字号 9；加工圆内编号在上、名称在下；
- 无填充色：三要素均为白底（与泳道图的色块风格不同，DFD 是白描风格）。

## 五、实现要点（pretty-charts / matplotlib）

- 外部实体：`Rectangle` 白底 + 深蓝边 1.1pt；
- 加工：`Circle` 白底深蓝边；**箭头端点 = 圆周交点**——从圆心沿连线方向求交点（圆心 + r·单位向量），**不是包围盒边**；进出圆的每条箭头都要按角度算；
- 数据存储：两条水平线段（左端开口、不封右），文字置于两线之间左对齐；
- 数据流：直线或正交折线 + `-|>` 箭头；标签沿线居中，**必须写数据名**；
- **分层平衡可脚本化**：维护"顶层进出系统边界的数据流集合"与"0 层跨边界流集合"，`set` 相等断言（防漏防多）；
- 输出 600dpi PNG + SVG 留存；等比回注 docx（纵横比不一致必须改 extent）。

## 六、硬规则（仓库踩坑汇总）

与《处理流程图制作方法.md》第五节共用：箭头端点精确落缘、标签净空 ≥2 单位不压线、xlim/ylim 收紧包围盒、字体直排列表、目检用新文件名、结构手术/换图后 WPS COM 打开验证再提交。DFD 特有：**指向加工圆的箭头必须按圆周交点计算**。

## 七、代码骨架

```python
import math
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib.patches import Rectangle, Circle

BLUE = "#1B3770"
plt.rcParams.update({"font.family": ["Times New Roman", "SimHei"]})

fig, ax = plt.subplots(figsize=(6.1, 4.4))
ax.set_xlim(0, 100); ax.set_ylim(0, 100); ax.axis("off")

def ext(cx, cy, w, h, name):
    ax.add_patch(Rectangle((cx-w/2, cy-h/2), w, h, fc="white", ec=BLUE, lw=1.1, zorder=3))
    ax.text(cx, cy, name, ha="center", va="center", fontsize=9, color=BLUE, zorder=4)

def proc(cx, cy, r, num, name):
    ax.add_patch(Circle((cx, cy), r, fc="white", ec=BLUE, lw=1.1, zorder=3))
    ax.text(cx, cy + r*0.45, num, ha="center", va="center", fontsize=9, color=BLUE, zorder=4)
    ax.text(cx, cy - r*0.45, name, ha="center", va="center", fontsize=9, color=BLUE, zorder=4)

def store(cx, cy, w, num, name):
    ax.plot([cx-w/2, cx+w/2], [cy-3, cy-3], color=BLUE, lw=1.0, zorder=3)
    ax.plot([cx-w/2, cx+w/2], [cy+3, cy+3], color=BLUE, lw=1.0, zorder=3)
    ax.text(cx-w/2+2, cy, f"{num} {name}", ha="left", va="center", fontsize=9, color=BLUE, zorder=4)

def rim(cx, cy, r, tx, ty):
    """圆周交点：从圆心指向 (tx,ty)，返回箭头应落的圆周点（进出加工圆必用）。"""
    dx, dy = tx-cx, ty-cy
    L = math.hypot(dx, dy)
    return cx + r*dx/L, cy + r*dy/L

def flow(p0, p1, label, lx, ly):
    ax.annotate("", xy=p1, xytext=p0,
                arrowprops=dict(arrowstyle="-|>", color=BLUE, lw=1.1,
                                shrinkA=0, shrinkB=0), zorder=2)
    ax.text(lx, ly, label, ha="center", va="center", fontsize=8.5, color=BLUE, zorder=4)
```

（实体/加工/存储的坐标按分层规范排布；每条 flow 的 label 必填；导出前收紧 xlim/ylim，600dpi 输出。）

## 八、质量检查清单（= 课件"第 6 步检查"）

- [ ] 外部实体齐全：数据的来源与去处都在图上
- [ ] 加工全部编号（顶层 1 个不编号；0 层 1~n；下层 x.y），名称为动宾短语
- [ ] 数据存储全部编号（D1~Dn），0 层图第一次出现
- [ ] **每条数据流都有名字**
- [ ] **分层平衡**：进出系统边界的数据流与顶层图一一对应
- [ ] 图上无判断菱形、无时序、无具体设备
- [ ] 600dpi 输出；目检（新文件名）通过后等比回注 docx；COM 打开验证
