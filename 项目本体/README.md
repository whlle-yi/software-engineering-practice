# 项目本体

本目录存放本课程大作业要开发的那套软件本身：原型、源代码、数据库脚本、运行资源。

它与 `第一次\`、`第二次\`…… 这些**文档提交目录**平级，原因：项目本体横跨需求、设计、实现三个阶段，不属于任何一次提交。

## 状态

**当前为空，尚未开始编码。** 课程进度到第 12 周（系统原型开发）才进入这里，前 11 周的工作全部是文档。

## 规划中的结构

选题确定后再按实际情况建，不预先创建空目录：

```
项目本体/
├── src/            源代码
├── db/             建库脚本、初始化数据
├── prototype/      原型（第 12 周前若要交原型，放这里）
├── assets/         图标、图片等静态资源
└── README.md       技术栈、启动方式、目录说明
```

## 规则

- **文档不进来**：说明文档、设计文档一律放对应的 `第N次\` 目录。
- **独立版本库**：本目录将来单独 `git init`，与文档仓库分开。代码和文档迭代节奏不同，混在一起会让提交历史难以阅读。
- **命名待定**：目录暂用中性的"项目本体"，选题确定后如需改成项目名（如 `校园二手书交易平台`），整个目录重命名即可，不影响任何文档内的相对路径——因为文档不引用这里的路径。
