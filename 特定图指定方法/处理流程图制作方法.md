# 处理流程图（泳道图）制作方法

> **用途**：跨角色的业务流程展示——突出"谁做什么"。
> **风格基准**：老师提供的图书借阅泳道图（2026-11-07 取色入库，色值见第二节）。
> **实现工具**：pretty-charts（matplotlib）之上的既定扩展——图元、坐标系、输出规范沿用 skill，样式按本文档覆盖。
> **本仓库状态**：待应用于可行性报告 3.1（现有系统人工排课流程）重绘；4.2 详细流程图是否同样式由用户决定。

## 一、何时用这种图

- 流程**跨越多个角色/系统**，需要一眼看出"每个环节谁负责"→ 泳道图；
- 单角色的纯步骤序列 → 普通流程图即可，不必强行分泳道；
- 数据的加工与存储表达 → 数据流图（DFD），不与本文档混用。

## 二、配色（实测自参考图，直接取用，不再走 business 默认色）

| 色值 | 元素 |
| --- | --- |
| `#001F5F` 深藏青 | 泳道标题栏填充、结束节点填充、全部连线与箭头、节点描边 |
| `#DEEBF7` 浅蓝灰 | 常规步骤节点填充、判断菱形填充 |
| `#FAE7E7` 浅红 | 异常/失败分支节点填充 |
| `#D34F4F` 红 | 判断文字、"是/否"分支标签、异常节点文字 |
| `#F5F8FC` 极浅蓝白 | 泳道内部底色 |
| `#CED4E0` 浅灰蓝 | 泳道分隔细线 |
| `#121212` 近黑 | 步骤节点文字 |

规则：红只用于"判断 + 异常"语义，不作装饰；藏青是唯一结构色。

## 三、版式规范（数字均为 0–100 画布单位，横向排泳道）

1. **泳道**：数量 = 参与角色数，纵向排列（角色为列）。泳道区总高 92（顶部留 8 给标题栏）；
2. **标题栏**：每泳道顶部一条深藏青圆角矩形，高 ≈ 7，宽 = 泳道宽 −2，白字加粗居中；标题栏与首个节点净空 ≥6；
3. **分隔线**：泳道边界细竖线（#CED4E0，0.8pt）贯穿泳道区；
4. **常规步骤**：浅蓝灰圆角矩形，宽 ≈ 泳道宽 55–65%，高 ≈ 8；同一泳道内水平居中；垂直按流程时序排布，相邻节点间距 ≥6；
5. **开始/结束**：开始 = 浅蓝灰（与步骤同款）；结束 = 深藏青实心、白字（终点感）；
6. **判断**：白底/浅蓝灰底菱形 + 藏青描边，宽 ≈ 泳道宽 60%、高 ≈ 12；出口旁红字"是/否"（就近、不压线）；
7. **异常分支**：浅红底、红字节点，尺寸同常规步骤；
8. **连线**：全部正交折线（先水平后垂直），藏青细线（1.1pt）、实心箭头；跨泳道必须水平进入目标节点侧缘；双向往来 = 两条平行线（间距 ≥4）；
9. **文字**：节点内文字近黑居中，最多 2 行；行内不用标点。

## 四、实现要点（pretty-charts / matplotlib）

- 坐标系：`xlim/ylim` 0–100，**导出前收紧到内容包围盒**（tight bbox 对铺满画布的 axes 无效）；
- 字体：`font.family = ["Times New Roman", "SimHei"]`（必须直排列表，serif 别名不触发逐字回退）；
- 图元：
  - 圆角节点 `FancyBboxPatch(round, pad=0.3, rounding_size≤0.8)`——**禁用大圆角路径**（Word/WPS 渲染会切平）；
  - 胶囊（开始/结束）= 矩形 + 两端 `Circle` 拼装，不用 FancyBboxPatch 大圆弧；
  - 菱形 = `Polygon` 四点；泳道/标题栏 = `Rectangle`；
  - 箭头 = `annotate("", xy=终点, xytext=起点, arrowprops=dict(arrowstyle="-|>", shrinkA=0, shrinkB=0))`，折线段用 `ax.plot` 逐段画、最后一段带箭头；
- 输出：600dpi PNG（docx 注入用）+ SVG 留存；PNG 等比回注 docx（纵横比不一致时必须改 extent，禁止直接换字节）。

## 五、硬规则（本项目踩坑汇总，逐条核对后才算画完）

- 箭头端点**精确落在框缘**：起点 = 源框边、终点 = 目标框边，逐个坐标核对；1 单位缝隙在 600dpi 目检图上肉眼可辨；
- 标签净空 ≥2 单位；任何文字不得压框线/压字；两框间走廊放不下标签 → 改两行或挪位；
- 面板/标题标签与最近图形净空 ≥2 单位；
- 收尾节点避免 FancyBboxPatch 大圆弧路径；
- 目检 PNG 用**新文件名**读取（防缓存旧图）；
- 结构手术/换图后必须 WPS COM 打开验证再提交。

## 六、代码骨架

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from matplotlib.patches import Rectangle, Circle, Polygon, FancyBboxPatch

NAVY, STEP, RED = "#001F5F", "#DEEBF7", "#D34F4F"
BG, LINE, TEXT, EXC = "#F5F8FC", "#CED4E0", "#121212", "#FAE7E7"
plt.rcParams.update({"font.family": ["Times New Roman", "SimHei"]})

fig, ax = plt.subplots(figsize=(6.1, 4.4))
ax.set_xlim(0, 100); ax.set_ylim(0, 100); ax.axis("off")

LANES = ["读者", "借书处（管理员）", "图书馆信息系统"]      # 换成实际角色
LW = 100 / len(LANES)
for i, name in enumerate(LANES):
    x0 = i * LW
    ax.add_patch(Rectangle((x0, 0), LW, 92, fc=BG, ec="none"))
    ax.plot([x0, x0], [0, 92], color=LINE, lw=0.8)
    ax.add_patch(Rectangle((x0 + 1, 84), LW - 2, 7, fc=NAVY, ec="none"))
    ax.text(x0 + LW / 2, 87.5, name, ha="center", va="center",
            fontsize=10, color="white", fontweight="bold")

def node(cx, cy, w, h, text, style="step"):
    if style == "end":
        ax.add_patch(FancyBboxPatch((cx-w/2, cy-h/2), w, h,
                     boxstyle="round,pad=0.3,rounding_size=0.8", fc=NAVY, ec=NAVY, zorder=3))
        ax.text(cx, cy, text, ha="center", va="center", fontsize=9, color="white", zorder=4)
    elif style == "exc":
        ax.add_patch(FancyBboxPatch((cx-w/2, cy-h/2), w, h,
                     boxstyle="round,pad=0.3,rounding_size=0.8", fc=EXC, ec=RED, zorder=3))
        ax.text(cx, cy, text, ha="center", va="center", fontsize=9, color=RED, zorder=4)
    else:  # step / start
        ax.add_patch(FancyBboxPatch((cx-w/2, cy-h/2), w, h,
                     boxstyle="round,pad=0.3,rounding_size=0.8", fc=STEP, ec=NAVY, lw=0.8, zorder=3))
        ax.text(cx, cy, text, ha="center", va="center", fontsize=9, color=TEXT, zorder=4)

def diamond(cx, cy, w, h, text):
    ax.add_patch(Polygon([(cx, cy+h/2), (cx+w/2, cy), (cx, cy-h/2), (cx-w/2, cy)],
                 closed=True, fc=STEP, ec=NAVY, lw=0.9, zorder=3))
    ax.text(cx, cy, text, ha="center", va="center", fontsize=9, color=RED, zorder=4)

def elbow(pts):
    """正交折线：pts=[(x,y)...]，末段带箭头，端点必须落在框缘。"""
    for i in range(len(pts) - 2):
        ax.plot([pts[i][0], pts[i+1][0]], [pts[i][1], pts[i+1][1]], color=NAVY, lw=1.1, zorder=2)
    ax.annotate("", xy=pts[-1], xytext=pts[-2],
                arrowprops=dict(arrowstyle="-|>", color=NAVY, lw=1.1, shrinkA=0, shrinkB=0), zorder=2)

def branch(x, y, text):   # 是/否
    ax.text(x, y, text, ha="left", va="center", fontsize=8.5, color=RED, zorder=4)
```

（节点/连线的具体坐标按第三节版式规范排布；导出前收紧 xlim/ylim，600dpi 输出。）

## 七、质量检查清单

- [ ] 泳道数 = 角色数；标题栏白字加粗；标题与首节点净空 ≥6
- [ ] 每个节点落在其责任泳道内、水平居中
- [ ] 箭头全部落缘、无悬空、无斜线；双向往来平行线间距 ≥4
- [ ] 是/否红字在位且不压线；异常分支浅红底红字
- [ ] xlim/ylim 收紧到内容包围盒；泳道间留白对称
- [ ] 600dpi 输出；目检（新文件名）通过后等比回注 docx；COM 打开验证
